# An Analysis's Verdict follows from its Claims' Verdicts, with a Partly false value

The Analysis Verdict used to band the mean falsehood of the Claims that had Evidence, so one well-supported true Claim could outweigh a refuted one. A forwarded message urging people to drink diluted bleach, next to a true sentence about paracetamol, came out true. Now the Verdict follows from the Claims' Verdicts. It is false if some Claims are false and none are true, true if some are true and none are false, Partly false if there are both, and uncertain otherwise. A true Claim never offsets a false one. Partly false has the Confidence of its strongest false Claim and no Credibility. The single-Claim gold set cannot catch this failure, because with one Claim the mean is that Claim.

## Considered Options

- **Keep the mean**: rejected. It turns the classic misinformation pattern of a false Claim wrapped in true ones into a true Verdict.
- **Any false Claim makes the Analysis false**: rejected. A sound article with one outdated sentence would get the same headline as a hoax, so "false" would mean two different things.
